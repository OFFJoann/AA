# Recursos locales del visor 360°

Este export no contiene las fotografías que descargaste en tu computador.

Archivos esperados: `frame-01.jpg` a `frame-36.jpg`, 1600 × 606 píxeles.
Origen de referencia: Corolla Cross Hybrid SE 2026, Toyota USA, color código d28.

Usa `node scripts/importar-360-local.mjs --source "RUTA_DE_TUS_IMAGENES"`
desde la carpeta autoamerica-react para comprobarlas. Agrega `--apply` para copiar.
No se sobrescriben fotografías distintas ni se eliminan los originales.

El visor es fotográfico, no una malla 3D desmontable. La correspondencia con
las versiones colombianas y el uso comercial siguen sujetos a revisión.
