# Vistas previas de compatibilidad

Estas capturas muestran los componentes modificados, ejecutados en Chromium con un entorno de prueba local React 18.2 disponible en este contenedor. Los iconos se sustituyeron por SVG locales en la prueba y el renderer Three.js no se ejecutó. **No son capturas de un build Vite/React 19 verificado**, de producción ni del sitio público. No se cambiaron las versiones ni los iconos del proyecto entregado para producirlas.

Las fotografías son los recursos del ZIP; el mapa externo queda pendiente de verificación. Las tarjetas sin imagen se muestran intencionalmente como fotografía pendiente.
